## See what every terminal is running.

The sidebar now recognizes CLI coding agents: **Claude Code**, **Codex**, **Pi**, and **OpenCode** tabs show the agent's mark and the folder it works in, including the git worktree when there is one.

### What's new

- **Agent icons.** A terminal running Claude Code, Codex, Pi, or OpenCode shows that agent's mark instead of the generic terminal icon, in the same quiet color as the rest of the sidebar.
- **Working folder.** Agent tabs gain a second line with the folder the agent runs in, written like a prompt (`~/Desktop/app`). Long paths keep the folder name visible; hover for the full path.
- **Worktrees.** When the agent works in a linked git worktree, the line shows the main repository and the worktree's branch. Switching branches updates it within seconds.
- **Codex detection.** Codex terminals are now recognized and titled like the other agents.
- **Right-click a tab** to **Rename**, **Pin**, or **Close** it. Opening Rename and leaving the name unchanged no longer freezes an agent's live title; clear the name to return to the automatic one.
- **Refreshed context menus.** Every right-click menu now matches the composer's menus, with icons where they help.
- **Cleaner terminal edge.** The scrollbar no longer adds a second gap on the right, and its gutter has no white outline.

### Installation notes

Windows 10 version 1809 or later / Windows 11, x64. Close Ash before running Setup. The installer is not code-signed, so Windows may show a publisher/SmartScreen warning. Verify the download source and checksums before proceeding.

Existing installations can also update in place from Ash.
