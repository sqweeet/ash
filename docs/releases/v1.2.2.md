## See when every agent is working.

Agent tabs now show a live working state: the tab title shines while **Claude Code**, **Codex**, **Pi**, **omp**, **OpenCode**, or **Muse Code** runs a turn, and stops when it waits for you. Ash also drops its built-in chat agent to focus on the CLI agents you run in its terminals.

### What's new

- **Working state.** A tab running a CLI agent shines while the agent works. Claude Code, Codex, omp, and Muse Code are read from their title spinners, Pi from its program status reports, and agents that report nothing (OpenCode) from their output activity.
- **Muse Code and omp.** Meta's Muse Code and omp (oh-my-pi) are detected, show their marks, and appear in the Agents section when installed.
- **Reorder tabs.** Drag a tab by its top or bottom edge to move it, within a workspace or into another one. Dropping on the middle of a tab still merges the two into a split.
- **Marquee titles.** Long tab titles fade at the edge and scroll on hover instead of ending in "…".
- **Emoji widths.** Emoji take two cells, as they do for ConPTY and TUIs, so table borders no longer zigzag.
- **Built-in agent removed.** The chat panes, model providers and API keys, background agents, Safe mode, chat history, and agent notifications are gone. Saved provider settings, including API keys, are deleted from `~/.ash/settings.json` on first launch.

### Installation notes

Windows 10 version 1809 or later / Windows 11, x64. Close Ash before running Setup. The installer is not code-signed, so Windows may show a publisher/SmartScreen warning. Verify the download source and checksums before proceeding.

Existing installations can also update in place from Ash.
