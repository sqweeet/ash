## A quieter desktop. A more reliable terminal.

**Gray** is Ash's new default: darker, neutral surfaces with soft, recognizable colors. No blue cast, no grayscale filter, and no changes to applications' truecolor output.

### What's new

- **Gray, by default.** A darker gray interface and terminal, with readable muted accents. New installations start here; existing theme choices are preserved. The earlier **Ash Gray** preference moves to **Gray** automatically. Change it anytime in **Settings → Appearance**.
- **Windows 11 caption icons.** Native-sized artwork, consistent line weight, and no gap beside the close button.
- **Better fullscreen scrolling.** TUIs keep their native mouse protocol; the wheel no longer injects arrow or PageUp/PageDown keys.
- **Correct terminal colors.** A bundled modern Microsoft ConPTY runtime preserves palette queries, early mouse setup, and Pi's colored tool-result panels. No separate Windows Terminal installation is required.
- **A single desktop backend.** The active app uses Go/Wails; obsolete Rust/Tauri dependencies and adapters have been removed.
- **Safer upgrades.** Setup asks you to close Ash instead of killing terminal sessions, replaces only Ash's own files, and does not wipe the install directory or your `~/.ash` settings and chats.

### Installation notes

Windows 10 version 1809 or later / Windows 11, x64. Close Ash before running Setup. The installer is not code-signed, so Windows may show a publisher/SmartScreen warning. Verify the download source and checksums before proceeding.

Terminal color and wheel fixes are included in both downloads. Existing windows keep running their old build until you restart them.

**Known limitation:** agent Safe mode uses a project copy and command review; it is not operating-system isolation. Review commands and merges before approving them.
